### 本轮从代码反向核对出的关键事实
- MQTT 报文类型共 **18 类**（上行 10 / 下行 8），非 20；`DictController` 注释写"16 种"是错的（记为 I-01）。
- `DashboardController.trend()` 注释称返回"任务数、在线车辆数"，实际只有 `accident` / `fault`（记为 I-02）。
- `VehicleController.detail` 返回**三段式** `{vehicle, latestState, position}`——前端若按顶层读会静默显示空。
- `LowState` 同时返回 `temperature`（协议原文 +100）与 `temperatureCelsius`（真值），是防漏减 100 的设计。
- 地图增强有**两条获取路径**：MQTT `mapehn/down` 推送 + HTTP `POST /manager/api/v1/event/mapehn` 每日 00:05 主动拉取
  （`RegulatoryGateway.fetchTodayMapehn`），以 `barrierId` upsert、`source` 区分 PUSH/PULL。
- 远驾接管有**两个异常标记** `driverMissing` / `durationMissing`，因远驾记录是责任认定依据。

### HTML 转换的六个坑（skill 已记录，本次实测验证）
1. **列表/表格前必须补空行**，否则 Python-Markdown 降级成纯文本（本次自动补了 1 处）。
2. **代码围栏不能嵌在引用块里**——`fenced_code` 是预处理器，看不见带 `> ` 前缀的围栏，
   内容会散成正文、`# 注释` 直接变 `<h1>`。**校验兜底：断言正文 `<h1 id=` 为 0**。
3. 表格单元格内行内代码的 `\|` 需还原。
4. `##### `（h5）在 TOC 与样式上都不受支持 → 本次把 10 个 h5 报文条目标题改成**粗体段落**。
5. Edge headless 截图：**URL 里的 `%E4` 百分号编码会被 PowerShell 安全策略误判为 cmd 语法而拦截** →
   先把 HTML 复制成 ASCII 文件名再用 `file:///` 截。
6. 校验必须做**六项**：元素计数（代码块/表格/h2/h3/h4/hr）、标题层级（正文 h1=0）、
   样式可达性（每个 class 都在 style 中定义）、锚点零失效、零外部请求、内容关键词探针。
   本次全部通过：44 代码块 / 142 表格 / 9-46-68 标题 / 55 内链 0 失效 / 0 外部引用。
