# DSSAD 云平台 · 用户操作手册

> 读者：平台运营人员、安全员、车队长（不需要编程背景）。
> 系统管理员/开发请看《开发与部署说明》与《服务启停与状态检测命令集》。
>
> 默认地址：控制台 `http://<服务器地址>/`（生产为 HTTPS）。
> 登录账号由管理员发放；生产环境的默认口令已被强制覆盖，请勿使用文档示例口令。

---

## 1. 登录与退出

1. 浏览器打开控制台地址，输入用户名与口令，点击「登 录」；
2. 登录后默认进入「运营总览」；
3. 退出：点击右上角头像 → 退出登录。**退出后令牌立即在服务端作废**，
   不是「前端删一下」——拿旧令牌再访问任何接口都会被拒绝；
4. 口令连续输错请稍后再试（登录接口有独立的限流保护，防止撞库）。

> 口令遗失：联系系统管理员重置。运营人员无法自助找回。

## 2. 运营总览（首页）

页面自上而下四块：

| 区块 | 怎么看 |
|---|---|
| 统计卡（车辆总数/在线/今日事故/待取证/今日故障/任务/远驾/阻断） | 「待取证事故」与「在线车辆」是每天必看两项；在线率 < 60% 变红 |
| 事故 / 故障趋势 + 故障分类分布 | 切换「近 7 天 / 30 天 / 90 天」看趋势；分类分布看主要故障来源 |
| 故障高发车辆 TOP10 + 故障码 TOP10 | 高发车辆用于安排检修优先级；故障码表看「次数」列排序 |
| 链路健康 | 入站队列持续增长 / 入站丢弃 > 0 时，截图报给运维（说明车端上报量已超过消费能力） |

页面每 10 秒自动刷新（右上角开关可关）；「本页最近一次加载」显示数据新鲜度。

## 3. 车辆管理

1. **查车**：顶部搜索框按 VIN/名称模糊检索，或按在线状态筛选；
2. **看详情**：点「详情」进入单车辆页 —— 实时状态（车速/SOC/续航/里程）、
   位置地图、轨迹回放（可选日期）、历史视频；
3. **轨迹回放**：选日期后拖动进度条；路线有抽稀（细节折线在大屏上做平滑），
   需要更精细的轨迹时缩小时间段；
4. **下发任务**：在车辆详情中下发轨迹任务（开始/结束），任务记录可在列表中核对。

## 4. 事件中心（事故 / 故障）

1. **筛选**：按时间区间、VIN、事件类型组合筛选；
2. **待归档事故**：页面顶部「待归档事故」卡片数量 > 0 时，下方出现红色「需催办」清单
   —— 这些事故已超过 10 分钟未收到取证材料，按清单逐台跟进；
3. **处理闭环**：每条事故可查看取证材料归档状态（已请求/已受理/待上传/已归档）。

> 事件 ID 是全链路唯一编号：向运维/监管报问题时**必须带上它**。

## 5. 远程驾驶

1. **发起接管**：填写 VIN 与发起人类型（1 交巡警 / 2 监管平台）→ 系统自动分配
   最久未使用的远驾舱与驾驶员，并同步上报监管平台；
2. **结束接管**：填同一 VIN 结束；接管时长自动配对计算；
3. **台账**：接管记录页可按车辆/是否结束筛选，驾驶员与时长用于事后审计。

> 注意：短时间内对同一车辆连续发起接管时，系统会自动把「结束报文丢失」的旧接管
> 闭合为异常结束，避免台账悬挂（页面无感知，记录里有日志）。

## 6. 地图阻断

1. **看图**：页面按当日生效的阻断设施绘制平面图（等比例、经度已做纬度修正）；
2. **看清单**：右侧清单按类型分组，点击任一行，平面图高亮该区域并显示详情
   （生效时段/限速/数据来源/回执状态）；
3. **立即同步**：正常情况每日 00:05 自动拉取；当日数据异常时可点「立即同步」手动补拉。

## 7. 视频取证

1. **待取证清单**：优先处理「待上传」状态的事故；
2. **取证材料归档**：车端四方向视频回传后在此页核对归档完整性；
3. **手动补录**：底部表单可关联 事故 ID / 摄像头方向 / 视频文件 手工上传补录；
4. **取证进度**：每个事故的材料到达情况在页面底部进度区汇总。

> 上传单文件上限 200MB；更大文件请分方向分别上传。

## 8. 链路监控（进阶）

| 你看到什么 | 说明 | 动作 |
|---|---|---|
| 通道状态 UP | MQTT 正常 | 无 |
| 通道 DOWN / RECONNECTING | 收不到车端数据 | 立即报运维（这是 P0） |
| 入站队列积压 | 报文进得来消费不过来 | 报运维，附积压数值 |
| 入站丢弃 > 0 | 数据已不可恢复地丢了 | 立即报运维（P0） |
| 限流触发次数 > 0 | 有车辆上报过猛被限流 | 结合 VIN 判断是否车端异常 |

> 「平台健康检查全绿」不代表收得到数据——通道必须看本页或让运维跑通道探针。

## 9. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 页面点菜单跳回登录页 | 令牌已过期（12 小时）或已在别处登出，重新登录即可 |
| 总览数字不更新 | 看页面底部「最近一次加载」时间；若时间不动，检查网络后点「刷新」 |
| 某车一直显示在线但联系不上驾驶员 | 在线=心跳在报，不代表有人；用轨迹页看车实际位置，必要时发起接管 |
| 上传视频失败 | 超过 200MB 或网络中断；分文件重传 |
| 地图阻断图空白 | 当日上游无数据；点「立即同步」，仍为空则联系运维查监管平台侧 |

## 10. 反馈与升级路径

1. 一般问题 → 企业内部运维群（附：页面名 + 事件 ID/车 VIN + 截图）；
2. 疑似数据丢失/通道中断 → 直接电话运维，并说明「链路监控页看到的现象」；
3. 功能需求 → 汇总后由项目管理统一排期（需求流程见《需求规格说明书》）。
