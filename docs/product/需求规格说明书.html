1. 项目概述#

车路通 DSSAD 产品云平台面向低速自动驾驶运营企业，提供：

  1. 车辆数据接入：接收车端经 MQTT 上报的运行状态、故障、事故、轨迹等数据；
  2. 运营管理：Web 控制台（车辆、事件、远驾、地图阻断、视频取证、链路监控）；
  3. 监管合规：按《平台数据对接接口文档 v1.0.0》向准入监管平台开放云云 HTTP 接口；
  4. 事故取证闭环：事故发生后联动下发取证请求、接收四方向视频归档、待归档催办。

2. 术语#

术语 定义
DSSAD 自动驾驶数据存储系统（车端记录装置），本文指其云端延伸
云云对接 企业云端 ↔ 监管平台的 MQTT（车云）/ HTTP+HMAC（云云）通道
待归档事故 已请求取证但尚未收到全部媒体文件的挂起事故
严重故障 severity ≥ 6 的故障（与后端 faultSevereToday 口径一致，前端不得另立阈值）

3. 用户角色#

角色 入口 关键操作
平台运营人员 Web 控制台（X-Token 登录） 全部管理功能
监管平台 服务对服务（HMAC 签名） 云云 HTTP 接口调用
车端 MQTT 通道（车云/企业网关） 状态/故障/事故/轨迹上报
交巡警/远驾舱 经监管平台或控制台 发起/结束远程接管

权限模型现状：单一角色（缺陷 P-08 已登记），RBAC 列入路线图。

4. 业务用例#

UC-01 车辆接入与实时监控#

运营人员登录控制台 → 总览查看在线率/今日事故/待取证 → 车辆列表检索车辆 → 详情页查看实时状态、轨迹回放、历史视频。

UC-02 事故取证闭环#

车端上报事故 → 平台经 MQTT 下发取证请求 → 车端四方向视频经 /manager 回传归档 → 事件中心「待归档事故」卡片计数，超 10 分钟未收到取证自动进入催办清单。

UC-03 远程驾驶接管#

交巡警/监管平台发起接管 → 平台 LRU 分配远驾舱与驾驶员 → 同步上报监管平台 → 结束接管自动配对（P-04 防御：新发起自动闭合悬挂旧记录；结束早于发起按孤儿落库）。

UC-04 地图阻断同步#

监管平台推送/平台定时拉取（00:05，分布式锁 P-01）当日阻断设施 → 平面图渲染 → 下发车辆生效。

UC-05 链路自证#

运维通过链路监控页查看 MQTT 通道状态、入站队列/丢弃、离线补传队列、限流触发次数， 配合 mqtt-watch.sh（退出码分级）实现「探活全绿 ≠ 收得到数据」的通道级验证。

7. 验收基线#

  1. mvn verify 全绿（用例数见《测试说明》），覆盖率门槛通过；
  2. npm run type-check + npm run build 零错误；
  3. bash scripts/health.sh 14 条断言全通过（含鉴权与登出失效）;
  4. bash scripts/mqtt-watch.sh --allow-disabled 退出码 0；
  5. 生产态：run-local.sh --prod 起服后 ddl-auto=validate 通过（实体与 MySQL 一致）。

8. 范围外（明确不做）#

  • 第三方地图底图接入（阻断区域本身即闭合多边形，叠加底图引入合规与加载失败风险）；
  • 乘用车 C 端功能（本产品只面向运营侧 B 端）；
  • 监管平台侧自身的功能演进（由监管方负责）。
