## 1. 背景：政策与行业驱动

### 1.1 监管侧的刚性需求

智能网联汽车（尤其低速自动驾驶：环卫、物流配送、园区接驳、矿山等封闭/半封闭场景）
在准入与上路试点中普遍被要求具备：

| 要求 | 来源 | 对本产品的意义 |
|---|---|---|
| 自动驾驶数据存储系统（DSSAD） | GB 汽车数据安全系列标准、准入试点通知 | 车端记录能力，本产品是**云端延伸** |
| 事故后数据取证与回传 | 各地智能网联汽车管理条例 | **事故取证链路是本产品的核心卖点** |
| 车辆运行状态上传监管平台 | 准入试点运行管理要求 | 云云对接（MQTT + HMAC）是准入的硬门槛 |
| 远程接管能力与接管记录 | 示范应用管理规范 | 远驾接管台账属于强监管数据 |

结论：这不是「锦上添花」的增值功能市场，而是**合规准入的必备件市场**——
不接入就上不了牌、拿不到示范应用资质，需求刚性极强。

### 1.2 行业侧的现实痛点

低速自动驾驶运营企业普遍面临：

- **多源协议碎片化**：车端由不同 Tier1 供货，报文格式各自为政，自研接入成本高；
- **自建平台重**：小体量运营企业养不起一个完整的车联网平台团队；
- **取证被动**：事故发生后数据在车端、云端、监管平台三处割裂，整理一次取证材料动辄数天。

## 2. 目标客户与用户画像

| 角色 | 画像 | 核心诉求 | 本产品对应能力 |
|---|---|---|---|
| 运营企业车队长/安全员 | 园区/环卫项目现场管理 | 知道每台车在哪、有没有出事、证照链路齐不齐 | 运营总览、车辆管理、事件中心 |
| 运营企业 IT 负责人 | 技术选型与对接 | 快速接入监管平台、少养运维 | 标准云云对接 + 开箱即用部署资产 |
| 监管平台（系统对系统） | 政府侧数据接收 | 数据按协议送达、可审计 | HMAC 签名云云接口、报文留痕 |
| 交巡警/远驾舱驾驶员 | 事故现场处置 | 一键接管、能拿到四方向视频 | 远驾接管、视频取证 |
| 平台运维人员 | 企业内部 | 好部署、好排障、告警准 | 部署资产、运维手册、三层探活 |

## 3. 竞争格局 **[待验证]**

| 竞品类型 | 代表形态 | 优势 | 劣势（本产品的机会） |
|---|---|---|---|
| 车企自建 TSP | 乘用车厂的车联网平台 | 与车端深度耦合 | 面向 C 端体验，不满足 DSSAD 监管口径 |
| 通用车联网 PaaS | 大厂物联网平台 | 生态全、扩展强 | 需要客户自己开发合规层，「买平台 ≠ 合规」 |
| 监管对接中间件小厂 | 单点对接工具 | 便宜、快 | 只做通道不做运营，取证与远驾能力缺失 |
| 运营企业自研 | 各家自建 | 贴合自身业务 | 成本高、协议跟进慢、人员流动即断档 |

**本产品定位**：面向低速自动驾驶运营企业的**「合规网关 + 运营平台」一体机**——
按《平台数据对接接口文档》实现标准化云云对接（准入即用），
同时交付事故取证、远驾接管、地图阻断等**强监管业务闭环**，而非裸通道。

### 3.1 差异化要点

1. **协议对齐即卖点**：与上游 PDF 接口文档逐条对齐并留有偏差记录（接口文档附录），
   接入验收不会卡在协议理解分歧上；
2. **取证链路完整**：事故 → 下发取证请求 → 四方向视频归档 → 待归档催办（超时提醒），
   证据链每一环都有审计状态；
3. **零依赖可落地**：本地 profile（H2 文件库 + MQTT 关闭 + 报文模拟器）让售前 POC
   可以「克隆即跑」，不依赖客户先备好 MySQL/Redis/Broker；
4. **运维友好**：探针退出码分级、备份三重校验 + 真恢复演练、应急剧本，
   面向「没有专职运维的小团队」设计。

## 4. 市场规模推算 **[待验证]**

推算口径（内部推演，需商务侧校准）：

- 低速自动驾驶示范城市数量 × 每城市运营企业数 × 单企业接入车辆数
  → 潜在接入车辆盘子；
- 按单车年化接入服务费（含云云对接 + 取证存储）定价区间估算年市场规模；
- 敏感结论不在本文档展开，另见商务内部材料。

## 5. 商业模式建议 **[待决策]**

| 模式 | 说明 | 适配场景 |
|---|---|---|
| 项目制交付 | 按企业/项目一次性交付 + 年维保 | 现阶段最现实 |
| 按车订阅 | 单车/年接入费，含存储与升级 | 车辆规模稳定后 |
| 存储阶梯计费 | 取证视频按存储容量/保留期分档 | 与《数据库设计》保留策略天然对齐 |

## 6. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 上游协议版本变更 | 云云对接返工 | 接口文档已建立「偏差记录 + 兼容层」机制（如 groute-resp 作用域 P-12），变更时改一处枚举 |
| 各地监管平台实现差异 | 一地对接 ≠ 全国通吃 | 协议适配层隔离（RegulatoryGateway 单点收口） |
| 取证视频存储成本 | 毛利被存储吃掉 | 保留策略可配（`DSSAD_TRACK_RETENTION_DAYS` 等）+ 生命周期清理任务 |
| 单一角色无权限分级（P-08） | 大客户安全审计过不了 | 列入路线图：RBAC + 高危操作二次确认 |
